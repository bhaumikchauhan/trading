# chart-patterns

Rule-based (and eventually ML-assisted) technical chart pattern detection over
OHLCV data — head & shoulders, cup & handle, double top/bottom, and more.

See [docs/functional-spec.md](docs/functional-spec.md) for scope and task status,
and [docs/technical-spec.md](docs/technical-spec.md) for architecture.

## Setup

```
uv sync
```

## Run tests

```
uv run pytest
```
